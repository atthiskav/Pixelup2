# PixelUp — Desenvolvimento Web

Site institucional da PixelUp, estúdio independente de desenvolvimento web.

## Executar localmente

Instale as dependências com `bun install` e inicie o ambiente de desenvolvimento com `bun run dev`.

## Observações

Este pacote contém o código-fonte do site. Arquivos de ambiente, credenciais, hospedagem e serviços externos não são incluídos. Configure as integrações necessárias antes de publicar.
